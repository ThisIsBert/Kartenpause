# Testkarten

Diese Projektdateien können in Kartenpause über **Laden** direkt geöffnet werden. Das jeweilige Rasterbild, die Referenzpunkte und eine gespeicherte Ausgangsanpassung sind in der JSON-Datei enthalten.

| Projektdatei | Punkte | Projektformat |
| --- | ---: | ---: |
| `534px-Australia_relief_map.georeferenzierung.json` | 5 | Version 1 |
| `Australien.angepasst.georeferenzierung.json` | 5 | Version 2 |
| `690px-Map_Germania_7-9.georeferenzierung.json` | 8 | Version 3 |
| `indusvalley.georeferenzierung.json` | 7 | Version 2 |
| `Roman-Empire-Map-AD-117.georeferenzierung.json` | 6 | Version 1 |
| `Roemisches-Reich.angepasst.georeferenzierung.json` | 6 | Version 2 |

Die Varianten mit älterem Projektformat bleiben absichtlich erhalten, um die Rückwärtskompatibilität beim Laden prüfen zu können. Vor einer Weiterverwendung oder Weiterverbreitung der eingebetteten Kartenbilder sind die jeweiligen Nutzungsrechte und Quellenhinweise zu prüfen.
